ResumeVerify — automated SST resume compliance checks

Upload modes

  • Option A — Google Forms CSV with Drive links in the Resume column
  • Option B — ZIP containing metadata.csv and PDF files
  • Option C — PDFs + optional metadata CSV/Excel

Verdicts

  • PASS — zero hard rule failures
  • REVIEW — at least one hard failure; management decides

API

  • GET /api/health — service health
  • POST /api/batch/forms-csv — Forms CSV upload
  • POST /api/batch — ZIP or PDF batch
  • GET /api/jobs/{id}/report — Excel report

See docs/decisions.md in the repository for rule thresholds and filename conventions.
